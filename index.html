🖼️ Subir una imagen nueva Más fácil

Usá Google Drive. No necesitás tocar el código.

1
Abrí Google Drive y subí la foto de la pieza (arrastrala o "Nuevo → Subir archivo").
2
Hacé clic derecho sobre la imagen → "Compartir" → cambiá el acceso a "Cualquier persona con el enlace" → Copiar enlace.
3
Volvé acá al panel → pestaña "Galería" → pegá el link y ponele un nombre → "+ Agregar foto". ¡Listo, aparece en la galería!
4
Si querés que aparezca como foto de un producto, andá a la pestaña "Productos", completá los datos y pegá el mismo link de Drive en el campo "Link imagen".
💡 El link de Drive tiene que quedar así:
https://drive.google.com/file/d/ABC123XYZ/view?usp=sharing
Si el link tiene ese formato, la imagen se va a ver correctamente.

📁 Subir una imagen a GitHub Requiere cuenta GitHub

Esto reemplaza una imagen permanente del catálogo base.

1
Entrá a github.com → tu repositorio → carpeta imgs/.
2
Hacé click en "Add file" → "Upload files". Arrastrá la imagen nueva. Importante: si reemplaza una existente, usá el mismo nombre (ej: tazas.png).
3
Scroll abajo → click en "Commit changes". En ~1 minuto Vercel redespliega automáticamente y la imagen nueva aparece en la página.
💡 ¿Cuándo conviene usar GitHub en lugar de Drive? Cuando querés reemplazar la foto oficial de un producto del catálogo (por ejemplo, sacaste una mejor foto de la tartera). Para fotos nuevas de la galería, Drive es más rápido.

🗑️ Borrar una imagen

Depende de dónde está guardada la imagen.

A
Si la subiste desde Drive: Andá a la pestaña "Galería" de este panel → buscá la foto → click en la ✕ roja. Desaparece al instante.
B
Si es una imagen base del catálogo (carpeta imgs/): Entrá a GitHub → carpeta imgs/ → click en la imagen → ícono de basurero 🗑️ → "Commit changes". Vercel redespliega en ~1 minuto.

💰 Actualizar un precio

1
Andá a la pestaña "Editar precios" de este panel.
2
Buscá el producto y cambiá el precio en el campo correspondiente.
3
Click en "Guardar cambios". Los precios se guardan en el navegador y se ven actualizados al instante.
⚠️ Importante: Los precios se guardan en este navegador. Si Nazarena los cambia en su celular, no se van a ver cambiados en el de otra persona. Para actualizar los precios para todos, hay que editar el código en GitHub (pedile ayuda a quien armó la página).
